# VSCode Cheatsheet

## よく使う操作

- ファイル検索: Cmd + P
- 全文検索: Cmd + Shift + F
- 定義ジャンプ: F12 / Cmd + Click
- 参照検索: Shift + F12
- シンボル検索: Cmd + Shift + O
- ターミナル: Ctrl + `

## tasks.json

Knowledge Labにはcheatsheetを開くタスクを用意します。Command PaletteからTasksを実行します。

## snippets

`usee`, `usf`, `clg`, `usel`, `used` などを用意します。

## console.log補完

`clg` snippetで、ラベル付きログを素早く置きます。

## ペアプロ時テンプレ

1. 目的を1行で確認
2. 関連ファイルを開く
3. 呼び出し元を検索
4. state / Redux / navigationを確認
5. 最小修正を提案
